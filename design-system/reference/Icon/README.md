# Icon

Íconos de trazo 1,75px en 24×24 que heredan `currentColor`.

- **Qué provees:** `name`, `size="sm"` (16px), `label` si el ícono va solo y significa algo; si acompaña texto queda oculto a lectores.
- El destello (`sparkle`) significa siempre “lo hizo o lo hace la IA”. No lo uses como decoración.
- Íconos propios del sistema, dibujados para él; ver la sección Iconografía.
