# Navigation

Navegación principal: barra inferior de tres pestañas en móvil, riel lateral en escritorio.

- **Qué provees:** `variant` (`bar` | `rail`), `active` (`hoy` | `productos` | `campanas`), `badges` (conteo por pestaña).
- Tres destinos: Hoy, Productos, Campañas. El asistente no es pestaña: se abre sobre la pantalla actual.
- Activo: ícono en píldora `primary-soft` y texto `primary`. El conteo de Hoy es la cantidad de decisiones pendientes.
- Desde 1024px (`bp-lg`) la barra se convierte en riel de `size-rail` con Ajustes al pie.
