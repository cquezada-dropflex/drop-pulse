# OfferPreview

Muestra cómo verá la oferta el comprador en la tienda.

- **Qué provees:** `title`, `price`, `compareAt` (precio tachado), `image`, `store`, `cta`.
- Usa colores fijos de tienda (blanco y tinta), no los tokens del tema: es una vista de otra superficie y no cambia con el modo oscuro de DropFlex.
- Siempre incluye “Paga al recibir”: es la promesa de venta contra entrega.
