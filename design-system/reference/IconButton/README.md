# IconButton

Acción de un solo ícono en barras y tarjetas; siempre con `label` accesible.

- **Qué provees:** `icon`, `label` (obligatorio: es el nombre accesible y el tooltip), `variant="primary"` para la acción de crear (círculo `primary`).
- Área de 44×44 aunque el ícono mida 20.
- El destello (`sparkle`) en la barra superior abre el `AssistantSheet`: es el mismo lugar en todas las pantallas de producto.
