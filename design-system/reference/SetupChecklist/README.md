# SetupChecklist

Tarjeta en Hoy con lo que falta configurar después del onboarding.

- **Qué provees:** `title`, `items` (`{ title, desc, done, action }`).
- Solo aparece si quedó algo pendiente (normalmente, Meta Ads). Se oculta con la x y reaparece en Ajustes.
- Lo hecho se tacha en gris; lo pendiente lleva un botón `secondary` pequeño. Nunca `primary`: la acción principal de Hoy sigue siendo revisar.
