# Metric

Una cifra con su referencia: el valor solo no dice si está bien o mal.

- **Qué provees:** `label`, `value`, `target` (la referencia: “Límite $6.000”) y `trend` (`good` | `bad` | `warn`).
- La referencia lleva ícono y color (`success` / `destructive` / `warning`); el valor queda en `foreground`.
- Se agrupan de a dos en móvil y de a cuatro en escritorio dentro de `df-metrics`.
