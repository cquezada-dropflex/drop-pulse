# SegmentedControl

Filtra una misma lista entre pocas vistas hermanas, con conteo.

- **Qué provees:** `options` (`{ value, label, count }`), `value`, `onChange`, `label` accesible, `block` para ocupar el ancho en móvil.
- Máximo tres opciones en móvil. Para Productos: Avanzan · Detenidos · Publicados; para Imágenes: Opciones · Elegidas · Descartadas.
- No es navegación: nunca cambia de pantalla.
